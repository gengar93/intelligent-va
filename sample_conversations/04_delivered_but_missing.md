# Delivered but Missing, with Escalation

## What this illustrates

- Treating a potentially serious delivery issue differently from routine tracking
- Asking focused diagnostic questions
- Avoiding unsupported claims about where a package is
- Creating a ticket and preserving the conversation summary

## Conversation

**User:** It says my package was delivered, but I don’t have it.

**Assistant:** I’m sorry about that. Is this about **ORD-1095**, the HomeChef mixer marked delivered today at **3:42 PM**?

**User:** Yes.

**Assistant:** The courier record says it was delivered to “reception/security.” Have you checked with your building’s security desk or anyone else at the address?

**User:** Yes, security doesn’t have it.

**Assistant:** Thanks for checking. I can report the package as missing and open an investigation with the delivery team. The investigation can take up to **48 hours**. Would you like me to proceed?

**User:** Yes, and I want a replacement.

**Assistant:** I can include your replacement preference in the report. A replacement can be approved after the delivery investigation confirms the loss. Shall I submit the report now?

**User:** Please do.

**Assistant:** The report has been created as **TKT-8044** with priority **High**. It includes:

- Order **ORD-1095**
- Marked delivered but not received
- Security desk checked
- Replacement preferred

You should receive an update by **10 August, 4 PM**.

**User:** Do I need to explain everything again if I contact support?

**Assistant:** No. The ticket contains this conversation summary. Give the support agent reference **TKT-8044**.
